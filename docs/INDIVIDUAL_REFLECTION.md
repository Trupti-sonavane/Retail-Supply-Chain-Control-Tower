# Individual Reflection
## Retail & Supply Chain Control Tower

Working on the Retail & Supply Chain Control Tower project has been a valuable learning experience. It helped me understand how data analytics can be applied to real-world retail and supply chain operations.

### Key Learnings

- Gained practical experience in SQL and PostgreSQL for data storage, querying, and KPI analysis.
- Learned to generate, process, and analyze datasets using Python and Pandas.
- Developed an understanding of inventory management, supplier performance, and shipment tracking.
- Implemented anomaly detection techniques to identify unusual demand patterns.
- Explored time-series forecasting using Prophet and evaluated model performance using MAE and RMSE.
- Built interactive dashboards using Apache Superset.
- Integrated Slack Incoming Webhooks to deliver automated supply chain alerts.

### Challenges Faced

During the project, I encountered challenges related to database connectivity, data integration, dashboard configuration, forecasting evaluation, and automation setup.

Working through these issues improved my debugging, problem-solving, and technical troubleshooting skills.

### Practical Experience

The project provided hands-on experience in connecting multiple technologies into an analytics workflow. I learned how raw datasets can be transformed into meaningful insights through SQL analysis, Python-based processing, forecasting, visualization, and alert notifications.

### Future Improvements

- Complete and verify automated data refresh.
- Enhance the dashboard with additional KPIs and interactive filters.
- Improve forecasting accuracy through further model experimentation.
- Strengthen end-to-end testing and validation.
- Expand alerting and anomaly monitoring capabilities.

### Conclusion

Overall, this project strengthened my technical knowledge and practical understanding of data analytics. It improved my confidence in working with databases, Python, business KPIs, machine learning techniques, and dashboard development. It also helped me understand the importance of data quality, testing, and documentation in delivering a reliable analytics solution.
